## クラス概要

イベント配信の接続先ごとに送信処理を管理する。前の送信完了を待って次のイベントを書き込み、同じ接続内の送信順序を保つ。

## フィールド/プロパティ

| 区分 | 可視性 | 型 | 名前 | 用途 |
| --- | --- | --- | --- | --- |
| フィールド | private readonly | Lock | _syncObject | クライアント一覧の排他制御。 |
| フィールド | private | Task | _sendTask | 直前の送信タスクを保持し、次の送信を連結する。 |
| コンストラクタ引数 | private sealed | StreamWriter | writer | 対象クライアントへのイベント送信先。 |

## メソッド一覧

| No | 可視性 | 戻り値 | メソッド名 | 概要 |
| --- | --- | --- | --- | --- |
| ① | private | - | EventClient | 接続先への送信処理を初期化する。 |
| ② | public | Task | EnqueueAsync | クライアント単位の送信タスクへイベントを連結する。 |
| ③ | private | Task | SendAfterAsync | 直前の送信完了後に1行JSONを書き込み、フラッシュする。 |
| ④ | public | void | Dispose | 接続先への出力ストリームを解放する。 |

### ②. EnqueueAsync

| 項目 | 内容 |
| --- | --- |
| シグネチャ | public Task EnqueueAsync(string message) |
| 可視性 | public |
| 戻り値 | Task |
| 戻り値内容 | 対象メッセージの送信処理を表すタスク。 |

引数:

| 型 | 論理名 | 物理名 |
| --- | --- | --- |
| string | イベントJSON | message |

処理内容:

- ① 排他制御内で現在の_sendTaskを取得する。
- ② SendAfterAsyncへ直前の送信タスクとイベントJSONを渡し、新しい送信タスクを生成する。
- ③ 新しい送信タスクを_sendTaskへ保持して返す。

備考: 同じクライアントに対する送信を呼出順に直列化する。

### ③. SendAfterAsync

| 項目 | 内容 |
| --- | --- |
| シグネチャ | private async Task SendAfterAsync(Task previousSend, string message) |
| 可視性 | private |
| 戻り値 | Task |
| 戻り値内容 | 1行JSONの書込とフラッシュを表すタスク。 |

引数:

| 型 | 論理名 | 物理名 |
| --- | --- | --- |
| Task | 直前の送信タスク | previousSend |
| string | イベントJSON | message |

処理内容:

- ① 直前の送信タスク完了を待つ。
- ② StreamWriterへイベントJSONを1行で書き込む。
- ③ StreamWriterをフラッシュする。

備考: 直前の送信が失敗した場合は例外を呼び出し元へ通知する。

### ④. Dispose

| 項目 | 内容 |
| --- | --- |
| シグネチャ | public void Dispose() |
| 可視性 | public |
| 戻り値 | void |
| 戻り値内容 | - |

処理内容:

- ① 送信用ライターの基底ストリームを破棄する。
- ② 切断済みなどにより破棄時に例外が発生した場合は処理を終了する。
