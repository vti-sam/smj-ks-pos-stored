## クラス概要

機器の接続先と通信条件を保持する。文字列で保存された通信条件を数値へ変換し、接続種別に応じた接続先を返す。

## フィールド/プロパティ

| 区分 | 可視性 | 型 | 名前 | 用途 |
| --- | --- | --- | --- | --- |
| プロパティ | public | string? | ConnectionType | 接続種別を保持する。JSON項目connectiontypeに対応する。 |
| プロパティ | public | string? | IpAddress | IPアドレスを保持する。JSON項目ipaddressに対応する。 |
| プロパティ | public | string? | Port | ポート番号を文字列で保持する。JSON項目portに対応する。 |
| プロパティ | public | string? | ComPort | COMポート名を保持する。JSON項目comportに対応する。 |
| プロパティ | public | string? | MacAddress | MACアドレスを保持する。JSON項目macaddressに対応する。 |
| プロパティ | public | string? | BtMacAddress | Bluetooth MACアドレスを保持する。JSON項目bluetoothaddressに対応する。 |
| プロパティ | public | string? | BaudRate | シリアル通信のボーレートを文字列で保持する。JSON項目baudrateに対応する。 |
| プロパティ | public | string? | Parity | シリアル通信のパリティを保持する。JSON項目parityに対応する。 |
| プロパティ | public | string? | DataBits | シリアル通信のデータビット数を文字列で保持する。JSON項目databitsに対応する。 |
| プロパティ | public | string? | StopBits | シリアル通信のストップビットを保持する。JSON項目stopbitsに対応する。 |
| プロパティ | public | string? | Handshake | シリアル通信のハンドシェイクを保持する。JSON項目handshakeに対応する。 |
| プロパティ | public | bool? | IsPrioritize | 決済端末利用時の優先フラグを保持する。JSON項目prioritizeに対応する。 |

### ④. GetConnectTarget

| 項目 | 内容 |
| --- | --- |
| シグネチャ | public string? GetConnectTarget() |
| 可視性 | public |
| 戻り値 | string? |
| 戻り値内容 | 接続種別に応じた接続先。設定がない場合はnull。 |

処理内容:

- ① ConnectionTypeを小文字へ変換する。
- ② bluetoothの場合はBtMacAddressを返す。
- ③ lanまたはtcpの場合はIpAddressを返す。
- ④ その他の場合はBtMacAddress、IpAddress、MacAddressの順で最初の非null値を返す。

備考: ConnectionTypeがnullの場合は④の順序で接続先を選択する。
