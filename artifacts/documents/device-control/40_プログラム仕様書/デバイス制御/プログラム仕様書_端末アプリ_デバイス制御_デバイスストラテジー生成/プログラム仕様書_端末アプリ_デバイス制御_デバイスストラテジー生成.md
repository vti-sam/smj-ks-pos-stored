## クラス概要

ストラテジーのクラス名と実装型を基底型単位で登録し、依存性注入コンテナーを使用して対象ストラテジーを生成するジェネリックファクトリーである。生成したインスタンスがDeviceStrategyBaseの場合は、デバイス仕様とアプリケーションロガーを設定する。

### 主な責務

- ストラテジー名と実装型の対応を基底型単位で保持する。
- 登録済みの型を依存性注入コンテナーから生成する。
- DeviceStrategyBaseのデバイス仕様とロガーを初期化する。
- 未登録名の指定を例外として呼び出し元へ通知する。

## メソッド詳細

### ①. Register<T>

| 項目 | 内容 |
| --- | --- |
| シグネチャ | public static void Register<T>(string name) where T : TBase |
| 可視性 | public |
| 戻り値 | void |

引数:

| 型 | 論理名 | 物理名 |
| --- | --- | --- |
| string | ストラテジー名 | name |

処理内容:

- ① ジェネリック型Tをストラテジー名に対応する実装型としてMapへ登録する。
- ② 同じストラテジー名が登録済みの場合は、新しい実装型で置き換える。

備考: 登録する型TはTBaseを継承または実装する必要がある。

### ②. Create

| 項目 | 内容 |
| --- | --- |
| シグネチャ | public static TBase Create(string name, DeviceSpec device, IServiceProvider serviceProvider) |
| 可視性 | public |
| 戻り値 | TBase |
| 戻り値内容 | 指定名に対応するストラテジーインスタンス。名前が空の場合はTBaseの既定値。 |

引数:

| 型 | 論理名 | 物理名 |
| --- | --- | --- |
| string | ストラテジー名 | name |
| DeviceSpec | デバイス仕様 | device |
| IServiceProvider | サービス取得元 | serviceProvider |

処理内容:

- ① ストラテジー名がnullまたは空の場合はTBaseの既定値を返す。
- ② Mapからストラテジー名に対応する実装型を取得する。
- ③ 実装型が未登録の場合は、ストラテジー名と基底型名を含む例外を送出する。
- ④ サービス取得元と登録型を使用してインスタンスを生成する。
- ⑤ 生成インスタンスがDeviceStrategyBase以外の場合は、そのまま返す。
- ⑥ DeviceStrategyBaseの場合は、DeviceSpecを設定する。
- ⑦ サービス取得元からIAppLoggerを取得して設定する。
- ⑧ 初期化済みのインスタンスを返す。

備考: DeviceStrategyBaseへ渡すDeviceSpecがnullの場合はInitInstanceからArgumentNullExceptionが送出される。必要な依存サービスが未登録の場合は依存性注入コンテナーから例外が送出される。
