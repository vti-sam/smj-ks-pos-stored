# Bộ tài liệu Device Control

Nguồn Markdown hiện hành được gom tại [device-control](../device-control/README.md). Tên hệ thống trong nội dung là タブレットPOS.

Bản bàn giao nằm dưới `0500_共通部品開発/2000_端末側/55_共通部品仕様書（デバイス制御）`, cùng bốn nhóm như nguồn: `10_利用方法`, `20_基本設計`, `30_詳細設計`, `40_プログラム仕様書`.

Tra cứu tên file và phiên bản thực tế trong `0400_ドキュメント一覧/ドキュメント一覧.xlsx`. Nội dung tham chiếu trong tài liệu dùng tên không kèm version.

Bộ hiện hành có 31 tài liệu, gồm 12 program spec Device Control và 14 program spec Device Connector. Các báo cáo cuộc họp trước và raw reference được giữ làm lịch sử, không dùng làm danh mục hiện hành.
