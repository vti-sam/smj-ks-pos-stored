## クラス概要

デバイスコネクタで発生したデバイスイベントを、接続中のタブレットPOS端末アプリへイベント通知用パイプで配信する送信部。イベント接続の待受、複数クライアントの管理、JSON形式での一斉送信、切断クライアントの除外を担当する。

### 主な責務

- イベント受信用クライアントの接続を非同期で待ち受ける。
- 接続済みクライアントの送信先を排他制御して管理する。
- デバイスイベントをJSONへ変換して全クライアントへ送信する。
- 送信失敗または待受失敗を記録し、利用できない接続を解放する。

### ②. Start

| 項目 | 内容 |
| --- | --- |
| シグネチャ | `public void Start()` |
| 可視性 | public |
| 戻り値 | void |
| 戻り値内容 | - |

処理内容:

- ① 待受タスクが既に存在する場合は何もせず終了する。
- ② キャンセルトークン発行元を生成する。
- ③ ListenAsyncをバックグラウンドタスクとして開始する。

備考: 同一インスタンスでの重複開始を防止する。

### ③. Stop

| 項目 | 内容 |
| --- | --- |
| シグネチャ | `private void Stop()` |
| 可視性 | private |
| 戻り値 | void |
| 戻り値内容 | - |

処理内容:

- ① キャンセルトークン発行元へ停止を通知する。
- ② クライアント一覧をロックし、全送信先を破棄して一覧をクリアする。
- ③ 待受タスクの終了を最大3秒待つ。
- ④ 待受タスクへの参照をクリアする。
- ⑤ キャンセルトークン発行元を破棄し、参照をクリアする。

備考: 待受タスクの終了待ちで発生した例外は停止処理を継続するため無視する。

### ④. Publish

| 項目 | 内容 |
| --- | --- |
| シグネチャ | `public void Publish(NamedPipeDeviceEvent deviceEvent)` |
| 可視性 | public |
| 戻り値 | void |
| 戻り値内容 | - |

引数:

| 型 | 論理名 | 物理名 |
| --- | --- | --- |
| NamedPipeDeviceEvent | デバイスイベント | deviceEvent |

処理内容:

- ① デバイスイベントをJSON文字列へ変換する。
- ② クライアント一覧をロックする。
- ③ 末尾から先頭の順で各クライアントへJSONを1行送信し、送信内容をフラッシュする。
- ④ 送信失敗時はイベントID、デバイスID、例外内容を含む異常ログを出力する。
- ⑤ 送信に失敗したクライアントを破棄し、一覧から削除する。

備考: 末尾から走査することで送信失敗した要素を安全に削除する。

### ⑤. ListenAsync

| 項目 | 内容 |
| --- | --- |
| シグネチャ | `private async Task ListenAsync(CancellationToken cancellationToken)` |
| 可視性 | private |
| 戻り値 | Task |
| 戻り値内容 | 接続待受処理の完了を表すタスク。 |

引数:

| 型 | 論理名 | 物理名 |
| --- | --- | --- |
| CancellationToken | キャンセル制御トークン | cancellationToken |

処理内容:

- ① キャンセルされるまでイベント送信専用のNamedPipeServerStreamを作成する。
- ② クライアントの接続を非同期で待つ。
- ③ 接続後、UTF-8（BOMなし）のStreamWriterを作成する。
- ④ クライアント一覧をロックし、送信先として登録する。
- ⑤ キャンセル例外時は作成中のパイプを破棄して待受ループを終了する。
- ⑥ その他の例外時は作成中のパイプを破棄し、異常ログを出力する。
- ⑦ 200ms待って次の接続待受を再試行する。

備考: 1件の接続登録後も次のクライアント接続を継続して待ち受ける。

### ⑥. Dispose

| 項目 | 内容 |
| --- | --- |
| シグネチャ | `public void Dispose()` |
| 可視性 | public |
| 戻り値 | void |
| 戻り値内容 | - |

処理内容:

- ① Stopを呼び出す。
- ② クライアント接続の待受を停止する。
- ③ 接続済み送信先、待受タスク、キャンセルトークン発行元を解放する。

備考: -

## 処理フロー/注意事項

- Startがイベント通知用パイプの接続待受を開始する。
- ListenAsyncが接続済みクライアントを送信先一覧へ追加する。
- Publishがデバイスイベントを全送信先へ配信し、失敗した接続を削除する。
- Dispose/Stopが待受と全クライアント接続を終了する。

### 注意事項

- NamedPipeDeviceEventはイベントID、関連要求ID、デバイスID、メソッドID、ハンドル、イベント種別、メッセージ、ペイロードを持つデータ契約として扱う。
- イベント送信はUTF-8（BOMなし）の1行JSON形式で行う。
